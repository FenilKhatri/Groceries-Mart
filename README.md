## ⚙️ Installation & Setup

#### 1️⃣ Clone the repo

```bash
git clone https://github.com/your-username/Groceries-Mart.git
cd Groceries-Mart
```

#### 2️⃣ Install dependencies

Client

```bash
cd frontend
npm install
```

Server

```bash
cd backend
npm install
```

#### 3️⃣ Environment Variables

Create .env file in server:

```bash
PORT=8000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
RAZORPAY_KEY_ID=your_key
RAZORPAY_KEY_SECRET=your_secret
```

#### 4️⃣ Run the project

```bash
# Backend
npm run dev

# Frontend
npm run dev
```
